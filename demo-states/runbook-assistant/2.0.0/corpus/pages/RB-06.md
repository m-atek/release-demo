Two gates run before anything is published.

## Quality gate

SonarQube Cloud analyses the service with the Sonar way gate, and the scanner waits for the result. A failed gate stops the run.

## SBOM and scan

Syft writes a CycloneDX SBOM of the package, and Grype scans it with fail-on critical. A critical finding stops the run before Publish, so the package never reaches JFrog. The SBOM and the scan report are attached to the change.
