store-sync runs on the six store servers, STORE-001 to STORE-006. Release it with `/release store-sync <Jira key>`; Alex approves the change, which lists every server.

## The waves

STORE-001 goes first, alone. Then two servers at a time. Every step runs through AWS Systems Manager Run Command: no server has an inbound rule, remote desktop or WinRM.

## When a server fails

A server that fails its check goes back to the previous version by itself, and the wave stops there. The servers after it are not touched. The change closes as "Successful with issues". Fix the server, then `/release store-sync <Jira key> resume` releases only the servers that are left, under a new change linked to the first.
