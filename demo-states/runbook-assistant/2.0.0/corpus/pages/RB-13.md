inventory runs on two cloud servers and two servers in the data center. Release it with `/release inventory <Jira key>`; Ansible deploys one server at a time.

## The data center

The data-center servers are reached by dc-agent, a Jenkins agent inside the data center that connects out to Jenkins over WebSocket with its own Cloudflare Access service token. Nothing in the data center accepts a connection from outside, so no firewall rule is needed. The cloud servers are reached through Systems Manager.

## When a server fails

Each release has its own folder and a current symlink. A server that fails its check switches the symlink back, restarts Tomcat, and the rollout stops before the next server.
