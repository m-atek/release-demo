Jenkins, JFrog Container Registry and Splunk run on one EC2 instance, the tools host, which accepts no inbound connections.

## Start and stop

`scripts/tools.sh up` starts it and waits until Jenkins, JFrog and Splunk answer, then prints "Ready". `scripts/tools.sh status` also lists any demo server still running. The host stops itself after 30 idle minutes: no running or queued build and no request through the Cloudflare tunnel. While it runs it costs about USD 0.19 an hour; its data stays on its own disk.

## When it is stopped

A /release or /rollback gets one line back: "The release server is stopped. Start it with scripts/tools.sh up."
