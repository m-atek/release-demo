The runbook assistant is released like any other service, with one more stage: Evaluation, after Check staging and before the change.

## The forty questions

Every version answers the same forty fixed questions against staging. A judge model scores each answer as correct and grounded in the passages it was given, and a script checks every page it cites. The gate is code: no answer may cite a retired page, and at least 36 of 40 must be correct and 36 grounded.

## Pass or stop

A version that fails stops before a change exists, and Slack says why. A version that passes ships as a standard change with its scores in the description and evaluation.json attached. The model writes answers and judgments only; nothing it writes approves a release.
