Deploy catalog from your laptop with the shared kubeconfig.

## Steps

Edit the image tag in deployment.yaml, then run `kubectl apply -f deployment.yaml -n production`. Watch the pods with `kubectl get pods -w`. If they crash, edit the tag back and apply again.
