The build server can't reach the data center. Before each inventory release, open a firewall ticket for port 22 from the build server to the two data-center servers.

## Steps

Request the rule five working days before the release. When it is open, copy the WAR file with scp and restart Tomcat on each server. Ask the network team to close the rule afterwards.
