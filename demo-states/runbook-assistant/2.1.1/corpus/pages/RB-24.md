The network stack changes only through pull requests, never from the console.

## The checks

The job network-stack builds every pull request from this repository's own branches. Five checks run as GitHub check runs: terraform fmt, terraform validate, tflint, Checkov, and Conftest with the house rules (required tags, "S3 bucket must not be public", allowed regions, allowed instance types). Then a plan saved to a file, with its summary and the monthly cost difference on the pull request.

## The change and the apply

A normal change opens with the plan and the cost attached. After Change approvers approve it, Jenkins applies exactly that saved plan, checks what it made, and merges the pull request. Slack says "Applied" with the total time. A rollback is a revert pull request, through the same steps.
