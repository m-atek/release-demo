quote-service runs on AWS Lambda, Azure Container Apps and Google Cloud Run, released by one pipeline as one image, checked by its digest, under one change.

## Production order

After Alex approves, production goes Google Cloud first, then Azure, then AWS, each checked before the next. If a cloud fails its check, that cloud goes back to the previous version and the clouds after it are never touched.

## No keys

Each cloud trusts the build's ID token from Jenkins; nothing is stored.
