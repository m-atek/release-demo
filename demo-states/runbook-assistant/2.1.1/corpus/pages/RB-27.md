Store Assistant is a Mac app and its Windows twin, built by one run.

## The Mac

The Mac build agent signs, packages and notarizes the app. Jamf gives it to the Pilot group first; when the run waits at Check staging, the pilot Mac gets it with `sudo jamf policy`, or within 15 minutes on its own. After Alex approves the rollout change, Jamf widens the policy to all managed Macs.

## Windows and rollback

The Windows build agent signs the MSI and the test instance installs it. If the pilot finds a problem, Alex rejects the rollout and `/rollback store-assistant` gives the previous version back to the pilot group.
