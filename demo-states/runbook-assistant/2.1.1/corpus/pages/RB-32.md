The pipeline keeps Jira and GitHub up to date, as the user Release Pipeline.

## Jira

At the start of a release it adds the fix version "<service> <version>" to the issue, creating it if needed. At the end it comments with the change number and the result, marks the version released and moves the issue to Done.

## GitHub

It tags the commit `<service>-v<version>`, for example orders-service-v1.4.0, and publishes a GitHub release with the notes: the change, the package path and its SHA-256, and the total time.
