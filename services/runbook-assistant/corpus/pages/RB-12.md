Upgrade the store servers one by one, in the evening, after the stores close.

## Steps

Open a remote desktop session to the server with the shared admin account. Stop the store-sync service, copy the new folder from the release share over the old one, and start the service. Check the log for errors, then move to the next server. Write each server and the time in the change form.

## If it breaks

Copy the old folder back from the share and restart the service.
