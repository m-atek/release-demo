If the pipeline's JFrog token appears anywhere it shouldn't, such as a Slack message, one command deals with it: rotate.py.

## What it does

It revokes the token in JFrog, issues a new one, stores it in SSM and reloads Jenkins, then proves the old token dead (JFrog answers 401) and the new one working (200). It opens a ServiceNow incident with the timeline and resolves it, replies in the Slack thread where the token was posted, and records the time from the leak to the old token being useless.
